# Superstore Sales Analysis | Power BI

A Power BI project exploring Superstore sales data to understand sales performance, product trends, customer behaviour, and shipping operations.

The dashboard is divided into four pages, with each page focusing on a different aspect of the dataset.

## Dashboard Pages

### 1. Executive Overview

Provides an overview of sales performance through KPI cards and charts showing monthly sales trends, sales by category, regional performance, and customer segments.

### 2. Product Performance

Looks at sales across product categories and sub-categories, including the top-selling products and monthly sales trends by category.

### 3. Customer Insights

Focuses on customer-level performance, including the top customers by sales, order frequency, average order value by segment, and a detailed customer sales table.

### 4. Geographic & Shipping Analysis

Explores sales across states and cities, order distribution by shipping method, and the average number of days between order placement and shipment.

## Tools Used

- **Power BI Desktop** — Dashboard design and visualization

## Dataset

The dataset used in this project is the [Sales Forecasting dataset on Kaggle](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting).

It contains Superstore sales records with information about orders, customers, products, geographic locations, shipping methods, dates, and sales amounts.

The dataset used in this analysis contains 18 original columns. It does not include Profit, Discount, or Quantity, so the dashboard focuses on sales performance, customer and product analysis, geographic distribution, and shipping duration.
